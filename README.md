## Какой-то проект на GitHub

1. Делаем Форк интерисуещего нас проекта (Копия на наш аккаунт)
2. Делаем git clone по ссылке в локальный репозиторий
3. Создаем новую ветку на которой работаем и затем все изменения сливаем push назад на Github и оттуда можно обратится для слияния с авторским Репозиторием pull request
